## 자체 제작 부스 앱
[최신 빌드 주소](https://github.com/2015kimdh/BoothApp/releases/tag/BugFixBuildVer0.1.2)
### 사용 가능 환경
- 안드로이드 기기 (iOS 미지원)
- 갤럭시 노트 20 울트라를 기준으로 UI 배치
- 안드로이드 OS 13 이상

### 제작 환경
- Unity 2022.3.22f1
- Unity C#
- JetBrain Rider
- Window 10

안드로이드 기기에서 사용 가능하며 부스 운영 매출 관리에 사용할 목적으로 제작했습니다.
주요 기능은 다음과 같습니다.
- 부스 별 항목 생성 가능 (부스는 이름 및 이미지 수정 기능을 제공하지 않습니다.)
- 판매 품목 등록 및 수정, 삭제 가능
- 품목 별 태그 설정 기능
- 판매 내역 조회 기능
- 판매 내역의 날짜 필터 기능
- 품목 별 판매 현황 조회 기능
- 품목 별 판매 현황에서 날짜 및 태그 필터 기능

한국어 버전으로 제작되었습니다.
최초 빌드 특성 상 UI 배치 및 기능에 버그가 있을 수 있습니다.

### 설치 방법
- boothApp.apk 파일 다운로드
- 다운로드 폴더에서 apk파일 실행
- 무시하고 설치 진행
- 설치된 앱 실행
